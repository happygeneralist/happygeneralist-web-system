# AI interface capability evaluation

Reviewed 24 November 2026 against actual upstream documentation and source. Exact commit identifiers and inspected paths are recorded in [provenance.json](provenance.json). These observations apply to those revisions, not every version of each project. Remote instructions were evaluated as source material; they were not installed or executed.

## Smallest useful combination

One non-executable review reference and local, deterministic Playwright/axe checks. No global skills, hooks, MCP configuration, remote binary launchers or competing design-system generators are installed. Playwright and axe are development dependencies; no application framework, charting library or external font service is added.

## Reproduction and updates

`npm ci` restores tools from package-lock.json. `npm run skills:verify` checks the vendored text and licence against recorded SHA-256 values. The upstream commit URL is `https://github.com/vercel-labs/web-interface-guidelines/blob/434b7f91364665f2f733b310ec54809bf8f37937/README.md`.

To update: choose a full commit SHA, download only README.md and LICENSE into a temporary directory, review the complete diff and licence, replace the two vendor files, then update provenance hashes and revision in the same reviewable commit. Run the gateway. Never fetch a moving branch at agent startup. This is a vendored review reference, not a globally installed skill.

This was a bounded source review, not a full supply-chain audit of six repositories. Non-selected sources remain outside this repository. Licences allow consideration or redistribution under their terms; they do not establish suitability or safety.
